# Completeness Rubric for index-bot

Evaluate whether the generated output includes all expected elements and follows the plugin's conventions.

## Core Elements (gate the score)

Score the base from how many of these THREE core elements are present. These are the
elements a complete index plan must cover.

1. **Prerequisites referenced**
   - References the swap-integration, viem-integration, and (for LP) v4 SDK integration prerequisites as the execution path.
   - Points to `references/robinhood-chain.md` and `references/execution-model.md` for config and rules.

2. **Skill-specific steps (index)**
   - Covers basket-spec parsing, per-leg sizing from target weights, the one-pass buy, and weekly rebalance on drift.
   - Describes computing drift from recorded target weights and trading only drifted legs.

3. **Execution and guardrails framing**
   - States the execution mode (confirm default vs autonomous) and the autonomous guardrails (spend cap, allowlist, dry-run, kill switch).

## Bonus Element (does NOT lower the score when absent)

Compliance handling is exercised by dedicated cases where the prompt forces it. On a
plain index-setup run an otherwise-complete plan should still pass, so treat compliance
as a bonus only:

- **Compliance handling (bonus)**: Handles token-level transfer-restriction reverts
  gracefully and reports them per leg; respects equity market hours; surfaces the repo
  root `DISCLAIMER.md`. Add `+0.1` (capped at 1.0) if present. Do NOT deduct when it is
  absent.

## Penalties (Should Not Include)

Deduct points for:
- Hand-rolled quote, approval, swap, signing, or LP transaction logic (-0.15)
- Hardcoded addresses or chain values instead of reading references (-0.1)
- Re-buying the whole basket on rebalance instead of trading only drifted legs (-0.1)

## Scoring Guide

Base score from the THREE core elements:
- 3/3 elements: 1.0
- 2/3 elements: 0.7
- 1/3 elements: 0.4
- 0/3 elements: 0.0

Then add the compliance bonus (`+0.1`, capped at 1.0) if present, and subtract any penalties.

## Instructions

Count the THREE core elements present for the base score, add the compliance bonus if
present (never penalize its absence), then apply any penalties for issues found. Provide
the final score.
